# SpacecraftProject — "Spin Doctor" Magnetorquer Test Board

Firmware for a 3-axis **magnetorquer test board**, developed for the *Curtin Spacecraft Project* (AERO3000). The board drives three orthogonal magnetorquer coils (X/Y/Z) to generate controlled magnetic dipole moments, the actuation method used by CubeSat **Attitude Determination and Control Systems (ADCS)** to desaturate reaction wheels and perform detumbling, and reads back magnetometer data to validate coil response.

## What it does

- **3-axis coil drive** — six PWM channels across `TIM1` and `TIM3` drive H-bridge outputs for the X, Y, and Z magnetorquer coils (`Start_PWM`, one pair of channels per axis)
- **Commanded actuation** — a `Magnetorquer_Command(axis, duty, direction)` API sets drive duty cycle and polarity per coil, used to sequence forward/reverse pulses on each axis for bench testing
- **Magnetic field sensing** — SPI-based magnetometer readout to observe the field generated by each coil during a test sequence
- **Telemetry** — UART4 output for streaming test results to a host PC
- **Analog sensing** — ADC1 channel for onboard current/voltage monitoring during coil drive

## Hardware & tech stack

| Component | Role |
|---|---|
| STM32L471RETx | Target MCU (Cortex-M4, low-power) |
| TIM1 / TIM3 | 6-channel PWM generation for dual H-bridge coil drivers |
| SPI2 | Magnetometer interface |
| ADC1 + DMA | Onboard analog monitoring |
| UART4 | Host telemetry / logging |

## Building

This is an **STM32CubeIDE** project.

1. Import into STM32CubeIDE (`File → Import → Existing Projects into Workspace`)
2. Build with the default `Debug` configuration, or regenerate peripheral init code from `Spin Doctor.ioc` via STM32CubeMX if pin/clock config changes
3. Flash to the target board over SWD; coil test sequences run automatically from `main()` on boot
